== Test Cases

=== TC_001 — Select File Group A

[cols="1,3", options="header"]
|===
| Field | Content

| *ID*
| TC_001

| *Requirement*
| FR_001

| *Priority*
| High

| *Description*
| Verify that the program correctly loads file group A when the user enters "A"

| *Precondition*
| Program is compiled and running; files NCAAdata.txt, NCAAinfo.txt exist in ../static/

| *Test Steps*
a|
1. Run the program
2. When prompted, enter `A`
3. Observe which files are loaded

| *Test Data*
| Input: `A`

| *Expected Result*
| Program sets dataFileSrc = "NCAAdata.txt", infoFileSrc = "NCAAinfo.txt", logFileSrc = "NCAAlog.txt" and proceeds without errors
|===

=== TC_007 — Champion and Runner-Up Correctly Determined

[cols="1,3", options="header"]
|===
| Field | Content

| *ID*
| TC_007

| *Requirement*
| FR_003

| *Priority*
| High

| *Description*
| Verify that the school with the higher score is assigned as champion and the lower-score school as runner-up

| *Precondition*
| Program started, file group A selected

| *Test Steps*
a|
1. Run the program and select `A`
2. Execute command `year[TAB]1982[TAB]1` to query champion
3. Execute command `year[TAB]1982[TAB]2` to query runner-up
4. Compare output to known data

| *Test Data*
| year = 1982; expected champion is the school with the higher score in the 1982 record

| *Expected Result*
| `Champion:` output matches the school with higher score; `Runner-up:` output matches the school with lower score

=== TC_017 — Log File Is Created and Closed Correctly

[cols="1,3", options="header"]
|===
| Field | Content

| *ID*
| TC_017

| *Requirement*
| FR_010, FR_011

| *Priority*
| High

| *Description*
| Verify that the log file is created in ../static/, contains the correct 3-line header, all command results, and is properly closed after processing

| *Precondition*
| Program started, file group A selected; ../static/ directory is writable

| *Test Steps*
a|
1. Run the program and select `A`
2. Wait for processing to complete
3. Open NCAAlog.txt in ../static/
4. Inspect header lines and command entries

| *Test Data*
| File group A; NCAAinfo.txt with at least 2 commands

| *Expected Result*
a|
- File NCAAlog.txt exists in ../static/
- First 3 lines: `Programmer: Zaki Malik`, `CS 1044 Spring 2009 Project 6`, `<data header label>`
- Each command is preceded by a separator line and a zero-padded 3-digit number (001, 002, ...)
- File is not locked after program exits
|===
