# NCAA Finals Statistics — Software Testing

## Project Overview
This repository contains the software testing artifacts for the NCAA Finals 
Statistics console application (C#), developed as a course work project.

## Tested Application
A C# console app that reads NCAA basketball finals data and processes 
three types of queries: `year`, `titles`, and `margin`.

## Repository Structure
- `src/` — Source code of the application under test
- `docs/` — Requirements documentation and full test report
- `test/` — Test cases and bug reports
